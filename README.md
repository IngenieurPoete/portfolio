Portfolio web haute performance développé en **React 18**, **Vite**, **Tailwind CSS**, **Lucide Icons** et **Framer Motion**.

---

## 🚀 Démarrage Rapide en Local

1. **Accéder au dossier :**
   ```bash
   cd portfolio-fadil
   ```

2. **Lancer le serveur de développement :**
   ```bash
   npm run dev
   ```
   L'application sera instantanément accessible sur `http://localhost:5173`.

3. **Compiler pour la production :**
   ```bash
   npm run build
   ```

---

## 🌐 Déploiement Gratuit en 2 Minutes sur Vercel (Recommandé)

1. Crée un nouveau dépôt public ou privé sur ton GitHub (`https://github.com/new`), nommé par exemple `portfolio`.
2. Initialise et pousse ce code :
   ```bash
   git init
   git add .
   git commit -m "feat: initial release portfolio Fadil Aboubakar Sidik"
   git branch -M main
   git remote add origin https://github.com/IngenieurPoete/portfolio.git
   git push -u origin main
   ```
3. Rends-toi sur [Vercel](https://vercel.com/) et connecte-toi avec ton compte GitHub.
4. Clique sur **"Add New Project"**, sélectionne ton dépôt `portfolio` et clique sur **"Deploy"**.
5. C'est tout ! En 30 secondes, ton portfolio est en ligne avec un lien mondial ultra-rapide (ex : `fadil-portfolio.vercel.app`) et se mettra à jour automatiquement à chaque nouveau commit.
